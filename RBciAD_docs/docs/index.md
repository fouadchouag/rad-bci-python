RBciAD — Reactive BCI Builder

RBciAD is a no‑code / low‑code environment to rapidly prototype Brain–Computer Interface (BCI) pipelines. It combines a drag‑and‑drop editor, a reactive engine (RxPY), and a polyglot plugin system (Python, native via pybind11/pyo3, subprocess wrappers) to deliver low latency EEG workflows that are easy to reproduce and evaluate.

Fast start: drop nodes, connect pins, results update instantly (no Run button).

Real EEG: MNE‑Python integration (EDF/BDF/GDF), authentic scrolling traces.

Polyglot: mix Python with high‑performance native steps or external tools.

Metrics: built‑in hooks for TTFP, FPS, CPU/RSS; artifact‑ready runs and tables.
