UI Tour
Canvas

Pan: Middle mouse / Space+Drag

Zoom: Ctrl+Wheel

Select: Drag box; Delete: Del

Snap‑to‑grid: optional toggle in View menu

Palette

Base Nodes: official nodes bundled with RBciAD

Custom: nodes you generate via the Low‑Code Editor or add to custom_plugins/

Single‑click to place a node on the canvas.

Nodes

Header with node title; pins on left (inputs) and right (outputs)

“?” badge in the top‑right corner opens Quick Help (Summary, I/O, Parameters, Usage).

Connections

Drag from an output pin to an input pin.

Edges reroute automatically when nodes move.

Invalid connections are rejected with a brief shake animation.

Properties Panel

Shows parameters for the selected node.

Typical buttons: Open (file), Enlarge (fullscreen plot), Info.

Shortcuts

Ctrl+N New, Ctrl+O Open, Ctrl+S Save

F1 Help Center, Shift+F1 Context Help

Del Delete selection
