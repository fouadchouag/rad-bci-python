    Nodes Catalog¶

    Auto-generated from plugin help dicts. Use Shift+F1 on a node to open its page.

    Analysis¶

    Node Summary
    PSDWelch Compute power spectral density via Welch's method from MNE Raw/Epochs or a raw segment array.

    BCI/Feedback¶

    Node Summary
    BCI_BallController Controls a 2D ball using classifier predictions. Maps pred_idx to directional actions (Left/Right/Up/Down/Idle) with physics simulation (velocity, friction, boundary bouncing). Supports confidence-weighted speed.

    BCI/Utils¶

    Node Summary
    BCI_CommandRouter Transforms classifier predictions into stable directional commands (LEFT/RIGHT/UP/DOWN/STOP) with confidence threshold, dwell time, majority smoothing, and refractory period. Optionally emits an LSL stream.
    BCI_Config No-code workflow config manager: scans all nodes in the workflow, provides a friendly UI to edit their parameters (auto-generated from export_config/config_hints), and supports preview/revert/apply (selected/class/all) plus preset save/load.
    BCI_MetricsViewer Displays trained model evaluation metrics from a BCI_Trainer report: CV accuracy ± std, balanced accuracy, F1 macro, confusion matrix, and per-class accuracy. Supports JSON and CSV export.
    BCI_OnlineMetrics Computes online rolling accuracy and cumulative confusion matrix by comparing pred_idx vs y_idx in real time.
    BCICollector Collect features and labels into a dataset dict for training. Supports manual recording or marker-based assignment.
    OnlineMetrics Computes online metrics by comparing pred_idx vs y_idx: rolling accuracy (window N), cumulative accuracy, Cohen's kappa, and cumulative confusion matrix. Auto-expands K when new class indices appear.
    {...}Hz Convertit des marqueurs LSL (strings) en y_idx (int) et y_name (str).

    ML¶

    Node Summary
    BCI_Features Extract EEG features: PSD band power, ERP mean windows, or time-domain statistics.
    BCI_Predictor Online BCI predictor: applies a trained model to incoming features and outputs class predictions with confidence.
    BCI_Trainer Train a scikit-learn classifier (LogisticRegression or LDA) in a background thread. Outputs a trained model and cross-validation report.
    BCI_TSFBCSPFeatures TS-FBCSP: Filter-bank tangent space features with OAS covariance.
    ClassifierMetrics Evaluates a binary dataset {X, y, y_names} from an upstream EEGClassifier using StratifiedKFold cross-validation with a StandardScaler + LogisticRegression pipeline. Displays accuracy ± std, precision/recall, and confusion matrix.
    ClassifierMetrics_1 Evaluates a multi-class dataset {X, y, y_names} using StratifiedKFold cross-validation with a StandardScaler + LogisticRegression pipeline. Displays accuracy ± std, macro-F1, and confusion matrix.
    ClassifierRuntime Applies a fitted sklearn classifier to a single feature vector, producing pred_idx, pred_label, and optionally a probability dict.
    CSPTrainer Train a Common Spatial Patterns (CSP) spatial filter from EEG trials and labels.
    EEGClassifier 2-class (Left/Right) EEG classifier with record-train-predict workflow.
    EEGClassifier_1 Multi-class (2-6) EEG classifier with record-train-predict workflow and optional auto-feature extraction.
    EEGClassifier_2 Advanced BCI trainer: multi-class (2-8) collect, CV cross-validation, train, predict, and dataset import/export.
    RiemannCov Compute the SPD covariance matrix from a single EEG segment.
    RiemannTSApply Apply a trained Tangent Space transform to project covariance matrices into 1D feature vectors.
    RiemannTSTrainer Train a Tangent Space mapping (pyRiemann) from covariance matrices and labels.

    Output Nodes¶

    Node Summary
    BallFeedback Moves a ball left/right according to classifier prediction — real-time BCI feedback visualizer.
    BandpowerInspector Visual inspector for band power features — displays per-channel band powers as a table or bar chart.
    EEGLiveDisplay Real-time EEG display with scrolling traces. Supports both raw (continuous) and segment modes.
    EEGSaver Save EEG data (MNE Raw or numpy segments) to disk in multiple formats.
    EEGVisualizer Simple real-time EEG viewer — displays raw MNE Raw data with selectable channels.

    MNE Viewer 2D (montage-free) MNE Viewer 2D — Montage-Free Plots (markers-ready)
    MNEBandpowerViewer Bar chart of EEG band powers (e.g. theta, alpha, beta), either averaged across channels or per-channel.
    PSDVisualizer Displays Welch PSD curves per channel with optional averaging and dB scaling.
    TFRViewer TFRViewer — robuste au changement de fichier / nbre de canaux

    Preprocessing¶

    Node Summary
    BCI_EuclideanAlignment Per-subject Euclidean Alignment for cross-subject BCI.
    BCI_Preproc Generic causal preprocessing for EEG: bandpass, notch, CAR, EOG regression, resample, z-score.
    MNEAverage Compute the mean across epochs to produce an MNE Evoked object.
    MNEAverageReference Apply average re-referencing to EEG channels of a Raw or Epochs object.
    MNEBandpassFilter Apply MNE-Python bandpass filtering to an MNE Raw object. Supports high-pass, low-pass, and FIR phase options.
    MNEICA ICA decomposition with automatic EOG/ECG artifact detection and removal on Raw or Epochs.
    MNENotchFilter Apply FIR notch filtering to remove powerline noise (50/60 Hz) and optional harmonics from Raw or Epochs.
    MNEResample Resample an MNE Raw or Epochs object to a target sampling frequency.

    Processing Nodes¶

    Node Summary
    BandpowerExt Extract band power features by delegating to an external bandpower script via subprocess.
    BandpowerExt_param Extract per-channel band power features using a built-in Welch-like estimator (no SciPy required).
    BandpowerFeatures Extract per-band power features from EEG segments using Welch PSD estimation.
    EEGChannelRMS Compute per-channel RMS (Root Mean Square) values from an EEG segment or MNE Raw object.
    EEGFilterStateful Stateful IIR bandpass filter for streaming EEG chunks.
    EEGRawFilter Temporal filtering (HP/LP/BP/Notch) for MNE Raw objects, with async background thread.
    EEGSliceFilter Streaming windowed filter (HP/LP/Notch) with persistent state (FIR or IIR).
    RawWindowSlicer Slices a continuous MNE Raw into overlapping windows via a QTimer.

    Segmentation¶

    Node Summary
    BCI_Epoch Extract fixed-length epochs from continuous EEG: sliding window or event-locked mode.
    MNEBaseline Apply a time-baseline correction to mne.Epochs via apply_baseline().
    MNEEpochs Create mne.Epochs from an MNE Raw object plus events (explicit or auto-extracted from annotations).
    MNEEpochsLite Minimal, robust epoching with automatic event detection (annotations → STIM → fixed-length → manual fallback).
    MNEEpochsToSegments Stream mne.Epochs one-by-one as segment arrays at a configurable frame rate, for live display.

    Time-Frequency¶

    Node Summary
    TFR (Morlet) Compute time-frequency representation (TFR) using Morlet wavelets on mne.Epochs, with safe auto-clipping of cycles.

    Transform Nodes¶

    Node Summary
    MNE Compute SSP Projs Compute SSP projectors for EOG/ECG artifact rejection on MNE Raw objects.
    MNE Set Montage Apply a standard electrode montage to an MNE Raw object with tolerant channel name matching.
